# TARA Foundation

TARA's initial runtime foundation is adapted from the public Manvi WhatsApp assistant.

Upstream: https://github.com/viswabnath/whatsapp-reminder-bot

The imported foundation provides the initial WhatsApp Cloud API integration, Supabase persistence, reminder/routine/recurring scheduling, web search, AI waterfall, conversational memory, usage tracking, health endpoints and tests. It will be progressively refactored into TARA modules.
